# iqdb-quantize v1.0.1

A fix release. No API changes.

## Fixed

- **Foreign PQ codes are an error, not a panic.** A code from a quantizer
  with a larger codebook (same dimension and subvector count) could carry a
  byte past the scoring quantizer's centroids, and `PqAdcTables::distance` or
  `dequantize` indexed out of bounds. Code bytes are now checked, and such a
  code returns `IqdbError::InvalidConfig`.
- **SQ8 on very wide ranges.** Training on finite values whose range exceeds
  `f32::MAX` overflowed the step size to infinity, and decoding produced NaN.
  The step size and, when needed, the decoded value are now computed in
  `f64`. Ordinary ranges produce the same codes and values as before.

## Upgrading

Change the version to `1.0.1`. Nothing else is needed.
